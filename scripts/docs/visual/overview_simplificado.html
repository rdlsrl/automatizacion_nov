Resumen simple — Sistema de Gestión Funeraria

Versión sin gráficos técnicos. Ideal para compartir con equipo no técnico.

1) ¿Qué es cada cosa?

Usuarios Dueño, Administración, Secretarías, Choferes (cada uno con permisos).
App Web Pantallas para contratos, inventario, pagos, RR.HH., panel y reportes.
Base de datos Guarda contratos, clientes, productos, pagos, empleados, liquidaciones.
Archivos Contratos, autorizaciones, facturas, fotos (respaldados en la nube).
Notificaciones Mensajes automáticos (WhatsApp) a familia y chofer de turno.
Contabilidad Exporta a tu sistema o banco para conciliación y estados.

2) Cómo fluye la información (paso a paso)

Secretaría crea CONVENIO/COTIZACIÓN/CONTRATO
  └─> Se guardan datos en la Base de Datos
      └─> Descuentos / Forma de pago / Adjuntos
          └─> Si hay productos, descuenta de Inventario

A fin de mes Administración aprieta “Calcular Liquidaciones”
  └─> El sistema calcula sueldo base + comisiones + bonos (noche/feriado/meta)
      └─> Genera PDF listo para pagar + archivo para el banco

En paralelo: Notificaciones automáticas
  └─> Al chofer: instrucciones del servicio
  └─> A la familia: tips (+4h), tarjeta (+5d), encuesta (+8d), oficios (+30d), aniversario (+1a)

3) Panel de control (qué veo)

  • Ventas del mes (por sucursal/secretaría/servicio)
  • Gastos por ítem (publicidad, combustible, insumos) y desviaciones
  • Rentabilidad y márgenes por servicio
  • Alertas: contratos impagos, stock bajo, documentos faltantes

4) ¿Qué hace fácil la administración?

  • Contrato único: los datos sirven para nómina, inventario y contabilidad
  • Botón de liquidaciones y botón de cierre mensual (PDF y export contable)
  • Adjuntos y respaldo automático (todo queda guardado con historial)
  • Mensajes automáticos: menos llamados manuales, más seguimiento

5) Glosario mínimo

  • Contrato: acuerdo con el cliente (número, fecha y hora, descuentos, servicios)
  • Inventario: productos y stock por bodega (rebaje automático)
  • Liquidación: cálculo mensual por empleado (base, comisiones, bonos, adelantos)
  • Auditoría: registro de quién cambió qué y cuándo
  • Copia en la nube: respaldo automático de datos y archivos
