Cómo se atiende y se ejecuta

  • La secretaría registra el contrato y adjunta documentos.
  • El sistema reserva inventario y planifica el servicio.
  • El chofer recibe instrucciones automáticas por WhatsApp.
  • Tras el servicio, se cierra con firmas y comprobantes.

Cómo se controla y se paga

  • Alertas por impagos, documentos faltantes o stock bajo.
  • Conciliación de pagos y emisión de recibos.
  • Liquidaciones mensuales: base + comisiones + bonos.
  • Panel con ventas, márgenes y desviaciones.
